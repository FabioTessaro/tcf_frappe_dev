# 103 · Frontend sdk

## Purpose

The small, versioned contract feature apps use to plug into the portal.

## Contents (`src/sdk/`)

| File | Purpose |
|---|---|
| `define-app.ts` | Helper to declare a manifest with full type checking |
| `manifest.types.ts` | Manifest shape: id, title key, icon, base path, navigation, routes, roles, party types, locale and style entries |
| `nav.types.ts` | Navigation items and groups rendered by the shell |
| `route-meta.types.ts` | Route metadata: roles, party types, title, layout, public mark |
| `permissions.ts` (+ test) | Role, party-type and capability helpers for showing/hiding UI (convenience only) |
| `index.ts` | Allow-list of what feature apps may import |

## Rules

- `FE-SDK-001` Besides `shared`, the sdk is the only part of core feature apps may import.
- `FE-SDK-002` The sdk is a public API with semantic versioning shared with the backend sdk
  version (`core_sdk_version`). Removing or changing an export is a major change.
- `FE-SDK-003` The sdk MUST stay small: new exports require a clear multi-app need.
