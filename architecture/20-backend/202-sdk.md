# 202 · Backend sdk

## Purpose

`<core-app>.sdk`: the only part of core that feature, foundation and site apps import. Small,
versioned, stable.

## Contents

| Module | Provides |
|---|---|
| `sdk.api` | `portal_api(roles=…, rate=…, deprecated_since=…)`, `integration_api(version=…, scope=…, rate=…)`, `guest_api(rate=…, cache=…)` decorators |
| `sdk.errors` | `ErrorCatalog` base, envelope builder, Frappe-exception mapping |
| `sdk.pagination` | List envelope (`items`, `total`, `cursor` or `page`) and helpers |
| `sdk.capabilities` | Capability protocols, fallbacks, `capability(name)` |
| `sdk.party` | Party helpers and party-scoping helpers |
| `sdk.settings` | Base for typed settings accessors |
| `sdk.realtime` | `publish(...)` |
| `sdk.jobs` | `enqueue(...)` wrapper propagating `trace_id`, user and audit context |
| `sdk.files` | `ingest(...)`, policy declaration, presigned transfers |
| `sdk.audit` | `audit(event, doc, reason=…, **data)`, read-audit helpers |
| `sdk.esign` | Electronic signature service |
| `sdk.classification` | Classification checks |
| `sdk.records` | Retention classes, legal hold |
| `sdk.roles` | Core role constants |
| `sdk.boot` | `portal_boot` hook contract |
| `sdk.logging` | Structured logger factory |
| `sdk.testing` | Test helpers: fake providers, party/user factories, site fixtures |

## Rules

- `BE-SDK-001` Apps MUST import from core only `<core-app>.sdk.*`.
- `BE-SDK-002` Every whitelisted function in a feature app MUST use exactly one of the sdk
  decorators (which apply `frappe.whitelist` themselves, never with `allow_guest=True` except
  `guest_api`).
- `BE-SDK-003` The sdk follows semantic versioning (`core_sdk_version`), shared with the frontend
  sdk. Removing or incompatibly changing a public name is a major change and requires a deprecation
  period of at least one platform release.
- `BE-SDK-004` The sdk MUST NOT import from any feature app.

## Extension points

- `BE-SDK-020` Apps MAY wrap sdk helpers in their own `<app>_shared` utilities; they MUST NOT
  re-implement them.
