# Playbook · Covering a new norm

1. Ensure the norm is in the register with its status (`CMP-REG-001`).
2. Break the norm into requirements; for each, decide whether it is met by platform rules, shared
   management-system primitives (`CMP-MS-001`) or a norm-specific app feature (`CMP-MS-003`).
3. Add rows to the traceability matrix with rule IDs, app features and evidence (`CMP-TRC-001`).
4. Implement missing features with [new-feature](new-feature.md); add new guide rules only for
   platform-wide needs (guide change, `FND-GOV-003`).
5. Update the coverage roadmap; mark rows `implemented`, then `verified` after internal audit
   (`CMP-TRC-002`, `CMP-RM-001`).
